# Start here

The slides that walk through all of this: [instructions.pdf](instructions.pdf).

1. Make sure you used **Use this template** on GitHub and cloned **your own**
   copy. Open the folder in VS Code.
2. Open a terminal: **Terminal → New Terminal**.
3. Run `npm install` — once, ever.
4. Submit your repo's link to the form, once, now: <https://forms.gle/xWbT6eoxfiFLC2eY9>
   You will need your name, your student ID, your tutorial number and your
   repo's URL.
5. Then work one folder at a time, in order, starting with `00-setup`:
   read its short `README.md`, then **run its `example.js` and read the
   comments — that file is the lesson**. Fill in `exercise.js`, and run
   `npm test 00` until it is green.
6. Commit and push when a module goes green.
7. Come back on **another day** for the next one. Spreading this out is part
   of the grade — you need commits on at least **6 different days**.

Stuck for more than twenty minutes? Ask. That is what we are here for.
